# Avant-Garde — plugin

The [Avant-Garde skill](https://github.com/Alexandre-LPZ/avant-garde): foundations before code. Six framing documents written through a plain-language interview, a 10-point security gate before go-live, `STATE.md` as the resume memory — a dying session only costs the wave in progress.

This cartridge is a **pure skill**: no hooks, nothing executes on your machine. Its mechanical rails will come after field observation, never before — we don't pour a rule into concrete until it has survived in prose.

## Install

```bash
claude plugin marketplace add Alexandre-LPZ/garde-fous
claude plugin install avant-garde@garde-fous
```

`/avant-garde:avant-garde` starts (or resumes) the framing in any session.

History, tests and releases: see the [skill repo](https://github.com/Alexandre-LPZ/avant-garde).
